# WeMoms Growth Audit

**Live → https://eddieatadapty.github.io/wemoms-flow-rebuild/**

Five ideas to turn more WeMoms users into subscribers, each built into a clickable version of WeMoms's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show her baby before asking for an account | +5–10% CR to purchase |
| 02 | Build the program from her answers, and say so | +10–15% CR to purchase |
| 03 | Ask for notifications where the reminder is promised | +10–20% notification opt-in |
| 04 | Make the yearly saving one she can check | +5–15% ARPU |
| 05 | Catch the people who close the paywall | +5–10% CR from paywall closers |

Every price, rating and feature comes from WeMoms's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for WeMoms. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
